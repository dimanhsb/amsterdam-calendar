# Check one source with Luna

Use this for a small refresh or to test whether a source guide is easy enough. Read `data/preferences.json`, then only the assigned source guide's Luna quick start. Use its historical notes only if the quick start points to a specific unresolved question.

```text
Check {source_domain} for Amsterdam activities from {start_date} to {end_date}.
Read source-guides/{guide_file} and follow its short Luna quick start.
Try one useful public page first. If text extraction lacks the visible content,
try the normal browser. Stop at login, security, booking or payment gates.
Do not keep repeating a failed route. Log the URL, method and exact failure.

Return a small evidence packet: title, exact date and year, start/end time,
venue/address, single-person joining rules, regular price and extras,
spoken language, source URL and what remains unknown. Check single visits;
Verify the displayed year and whether an extract is stale or cached.
memberships or private-group prices do not establish public drop-in access.
Keep free entry, fixed price, tips and donation distinct. Do not infer dates
from recurrence or language from the webpage. Skip the saved blacklist.
Apply the current profile settings when flagging preferred hours. Use Europe/Amsterdam with the correct
date-specific offset. Do not book, pay, contact, create accounts or change data.

If the guide is hard to follow, say exactly where and propose 3–5 simpler
steps using only navigation you actually observed. Retest a changed route.
Distinguish a wording problem from an inaccessible website. Report zero yield
honestly. Android is a separate bounded fallback; never claim it was tested
unless it was. Save reviewed candidate records using the batch template.
```

Start with one source and 5–10 candidate records. Check the audit's next step before spending time on blocked sources. A source spot check does not establish that every event or price is still valid. A new full audit needs a fresh inventory and baseline guide hashes; do not reuse the dated 18 October audit as if it were a new run.
