# Open Week · Amsterdam

A static activity calendar and research snapshot for Amsterdam. Event details include source links, dates, prices where known, and uncertainties. Coverage currently runs through November 2026; listings are historical and should be confirmed with organizers.

## Run locally

Requires Python 3 and Node.js; no package installation is needed.

```sh
npm run build
npm run check
npm run dev
```

Open http://127.0.0.1:4173. Picks and preferences are stored locally in your browser. The public source includes curated event data and research summaries; the original working archive is not included. The build uses checked-in summaries and does not regenerate the historical research.

Event listings and other third-party material remain subject to their respective owners’ terms.
