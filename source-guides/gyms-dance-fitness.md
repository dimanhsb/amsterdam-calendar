# Amsterdam gym and dance-fitness source guide

Checked 2026-10-18. Use these official routes to find a genuinely single-visit route into Zumba or comparable dance fitness. Treat weekly schedules as leads only: do not create dated records from recurring weekday timetables. A dated record needs a publicly stated exact date and start time inside the coverage window, and the event must meet the weekend / weekday evening / weekday morning ending by 10:00 filter.

## Best verified lead: FemmeGym De Smederij

- Club page: https://www.femmegym.nl/femmegym-de-smederij/
- General offer page: https://www.femmegym.nl/het-aanbod/
- Navigate to the Smederij page, then the “Free Day Pass” or “Get a free day pass” link. Do not submit the form during research.
- The club page states that a free day pass permits one class or use of the free-training room; its class list names Zumba. This is a real one-visit class possibility, not a recurring membership. The club is a women’s gym, so state that eligibility condition instead of assuming the user is eligible.
- The page separately lists a €9.99 three-workout trial package. Keep this distinct from the free single-day pass.
- The embedded public Virtuagym weekly schedule defaulted to Week 42 (12–18 Oct 2026) when rendered on 18 Oct. It showed Zumba Fri 12:15–13:10, outside the preferred time window. The club page did not expose a future one-off dance date. The timetable’s visible weekly recurrence is not evidence of target-date one-off admission.
- Schedule reservation and free-pass eligibility terms were not stated in the page. Verify them from the visible class/pass flow if a suitable upcoming class is found, without submitting a request or booking.

## Efficient update procedure

1. Start with official city/branch pages that name Zumba, Dance, Afro Beats or Les Mills Dance, not generic gym directories.
2. Open the public class timetable and look for an exact public date, start and end. If it only shows a normal repeated week, record it as schedule evidence or an undated offer, never as a date occurrence.
3. Check the same organizer’s day-pass rules. Capture whether a class is included, whether a class booking is required, whether the pass is truly one-off, and any first-timer or audience eligibility. Mark unresolved items unknown.
4. Check the start and end against local time: Amsterdam is UTC+02:00 through 2026-10-24 and UTC+01:00 from 2026-10-25 onward. Apply the current profile settings when selecting times.
5. Check the existing event and offer IDs before adding anything. Add a source-guide note with the checked date, exact URL, observed schedule horizon and price evidence.
6. Never complete a signup, create an account, request a trial, book, pay, or contact an organizer while collecting public evidence.
