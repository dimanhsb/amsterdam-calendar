# DagjeWeg.nl source guide

## Luna quick start · checked 18 October 2026

DagjeWeg is a broad outing directory. Start at the homepage, filter to Amsterdam and the requested dates, then open an allowed listing. The current homepage surfaced Amsterdam museum tips but no dated event packet.

1. Open the homepage and set Amsterdam plus the requested date range.
2. Skip climbing/bouldering listings.
3. Open one allowed result and copy its displayed title, date/time, price and access terms.
4. Stop if the listing gives only opening hours or lacks an individually dated occurrence.

Untested controls: Any filter, date picker, schedule link or booking control not explicitly recorded in the observations was not clicked during this audit.

Copyable prompt: “Using https://www.dagjeweg.nl/, find allowed public entries from {start_date} through {end_date}. Skip climbing and bouldering. Return only displayed dated entries with title, date/time, single-visit price and access terms; mark missing fields unknown. Stop if no individually dated entry is listed.”


Historical note: the directory has since been reviewed as a broader source.
